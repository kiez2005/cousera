# Simple Interest Calculator

A simple interest calculator that computes interest based on user input.

## Description

This project provides a Bash script to calculate simple interest given:
- **Principal** – the initial amount of money
- **Rate of Interest** – the annual interest rate (in percentage)
- **Time Period** – the duration (in years)

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Usage

1. Clone the repository
2. Run the script:
```bash
   bash simple-interest.sh
```
3. Enter the required inputs when prompted
